# Sign-in slideshow photographs

The sign-in page turns through four slides. Each one looks here for a photograph:

    slide-1.jpg   Built for microfinance
    slide-2.jpg   Collections
    slide-3.jpg   Control
    slide-4.jpg   Fair to borrowers

None ships with the code, because a stock photo needs a licence. Until one is
dropped in, a slide shows its animated scene alone, which is a finished look on
its own. A landscape JPEG around 1600 x 1200 looks best; it is shown at about
half strength under the scene's colour, so a busy picture still reads calmly.
